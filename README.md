# AudienceIQ — Pre-Publish Content Performance Predictor

Built for the **Qatar Science & Technology Park (QSTP) Stars of Science Hackathon 2026** — Challenge 01: Audience Intelligence.

🔗 **Live demo:** [mvp-audience-dovb6933g-mvp88.vercel.app](https://mvp-audience-dovb6933g-mvp88.vercel.app/)

## What It Does

AudienceIQ is a pre-publish content analyzer that predicts how a piece of content is likely to perform on different platforms, based on the creator's specific goal:

- **Applicants** — content aimed at attracting job/program applicants
- **Viewers** — content aimed at maximizing views/engagement
- **Sponsors** — content aimed at attracting sponsorship interest

Creators can check predicted performance *before* publishing, with geographic insights scoped to Arab-country audiences.

## How It Was Built

Built within a 48-hour hackathon window, with a focus on shipping a working, demoable product over a fully-integrated backend:

- **Frontend & logic:** TypeScript, built mainly using Replit
- **Data approach:** Mock/hardcoded datasets, used intentionally to prioritize a stable, demoable MVP within the time limit. Integrating a real AI/ML scoring API was scoped but deprioritized in favor of finishing a complete, working flow.
- **Deployment:** Migrated from Replit to **GitHub + Vercel** for the final submission and live demo — my first time setting up a GitHub → Vercel deployment pipeline.
